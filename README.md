# Health Is a Team Sport

An interactive single-page editorial magazine arguing that the most underrated fact in health is other people.

Static site — plain HTML/CSS/JS with GSAP ScrollTrigger. No build step: serve the folder with any static server.

Artwork generated with fal.ai (nano-banana-pro); chapter-five photography from Unsplash, credited in the colophon. Written by [Simone Staffa](https://simonestaffa.com).
